# 0.5.2 动画轮转与任务文案审查

本轮以“默认活泼、动作完整、文案跟随任务”为目标，不增加素材数量。现有姿态已经包含空挥准备、躲闪、恢复打字；主要问题是时间安排与多个调度入口互相干扰，单纯重复帧不能修复。

| 原问题 | 修复 |
| --- | --- |
| 空闲动作和气泡共用短预算，举牌容易错过 | 经常/偶尔互动动作保留 12 秒，气泡 6 秒后隐藏；内置大肥鱼有台词时每两次至少一次举牌，避免相邻动作重复；空台词仍允许非文字小动作 |
| 默认安静，工作文字仅在类别变化时换 | 新设置默认经常互动、活泼动作、偶尔换话、随机空闲台词；已保存的偏好保持原样 |
| 空挥频率可把整套反应挤到半秒内 | 一次空挥约 0.95–1.35 秒，随后保持恢复工作姿态 2.5 秒；保持期间鞭子不显示，连续轮次之间不闪入一帧普通姿态 |
| 躲闪同时进入普通工作随机池 | 躲闪仅由统一空挥节拍驱动，关闭开关时立即停止 |
| 速度跨区间、工具变化导致动作频繁替换 | 普通动作最短自然 18 秒/活泼 12 秒，速度波动不提前逐出；工具姿态最少 4 秒并等待循环边界，连续事件只保留最新目标 |
| 外部角色在空挥下面继续播放，回来时已经换动作 | 反应期间暂停普通动作时钟；一次性动作至少保留末帧 2.5 秒；同一 greeting 可以在下一次空闲预算内重播 |
| 同类别的新工具调用不换文案 | 用当前调用 ID 识别新事件；短时间多个事件合并过渡文案，实际工具/文件/进度仍更新 |
| 用户看不出正在处理哪条消息 | 气泡增加本轮用户消息短提示（48 字），支持 `{task}`，可单独关闭；不读取推理或工具结果，不额外调用模型或持久化聊天 |

确认、失败、取消、切换会话等关键状态仍可立即打断。未知工具继续回退到通用动作。普通工具的长循环最多延后 6 秒，外部一次性长动作最多延后 10 秒，防止作者配置无限拖延。

## 台词补充

发布版将全部 20 类默认台词补齐为每类 8 句，共 160 句，包含工具/文件/任务变量。用户自定义与角色包专属台词仍优先，空列表继续静音。完整可编辑模板在 [default-dialogue.json](default-dialogue.json)。

## 验证

- 类型检查、125 项单元测试通过；针对连续空挥、末帧保持、压力抖动、工具合并、空闲预算、同类工具文案和原生任务摘要增加断言。
- 29 项 Chromium 浏览器回归通过，包含真实 Canvas 的保持帧、举牌与文字分离、十分钟安静模式、深浅主题和角色包。
- DSH `0.1.5-rc.2` 原生隔离环境从 0.5.1 升级到 0.5.2，通过 14 项流程检查：实时消息、任务摘要、扩展进度、多会话、设置与角色保留、备份恢复及卸载；未调用付费模型。
- 本机 3080 Web profile 已安装 0.5.2，确认没有运行中任务后，以原环境重启；升级前后设置文件保持原样；随后按本轮诉求把当前工作台词改为“偶尔说一句”，其余自定义内容保留。其他平台及长时间运行沿用历史验证范围，不冒充本轮新测。

这轮没有绘制新的独立原画帧。保持阶段复用已到位的姿态，使用户有时间看清；后续增加中间姿态仍可通过现有序列/每帧时长扩展。
