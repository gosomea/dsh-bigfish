# 智能宠物开发版

当前版本 `0.7.0-next.1` 面向 Web 预览，使用 npm `next` 标签。正式全能版的开发和验收进度见[开发状态与未完成项](plans/intelligent-pet/implementation-status.md)。

## 配置

完整设置分为四页，默认打开日常陪伴。切页保留未保存草稿，关闭按钮始终可见。智能设置、台词与工具、活动精确参数或活动区域存在未保存修改时，关闭、返回快捷设置或手动重新读取会先显示确认；取消后原样继续编辑，无草稿时不增加步骤。确认只列出草稿名称，不复制台词、授权或区域内容。菜单、输入框、开关和滑块跟随 DSH 的明暗主题；下拉菜单支持方向键、Home／End、输入查找和 Enter 选择，Escape 先关闭菜单并恢复焦点，不误关整个设置。菜单在屏边换向、随滚动调整，锚点离开设置可见区域后关闭。

| 页面 | 常用入口 |
| --- | --- |
| 日常陪伴 | 当前角色与更换、陪伴方案、活跃程度、说话频率、活动范围、显示场景、鞭策开关；智能模式显示状态与用量入口。动作幅度、举牌和首次问候放在“更多陪伴偏好”。 |
| 智能管家 | 模型、工作范围、启用开关与今日用量直接显示；预算等高级参数、记忆与任务本按需展开。语音与主动分享单独展开。 |
| 外观与生活 | 显示与大小、角色库及动作预览、工作布景、气泡、小窝、装扮、成长和真实收藏。 |
| 高级与数据 | 自定义能力与称呼、命名方案、台词与工具规则、完成反馈、专家参数、备份与恢复。 |

陪伴方案提供均衡、温柔陪伴、认真管家、淘气搭子、共同成长、可交谈助手和全能预设。修改能力后标记为自定义；命名方案还会保存角色标识、外观、活跃程度、动作幅度、说话频率和鞭策偏好。切换和导入先展示具体前后值再应用。全能型显示为“全能型 · 预览版”。首页“功能状态”按当前角色、Host、设备和配置分别显示可用、待配置、当前角色未支持、已关闭或模拟演示，并说明桌面专属能力。选择全部功能不等于开启模型、麦克风或截图；正式桌面发行是否验收另行记录。

新版导出是 `version:2` 方案，兼容原有裸 `version:1` 生活配置和旧命名方案；旧格式只改生活选择，不覆盖新的显示偏好。文件不包含角色包本体、私人台词、工具规则、任务、记忆、权限或预算。角色包尚未安装时明确提示并保留当前角色，不自动下载。应用方案保留本次安静状态；恢复显示与行为不会删除命名方案，恢复类型是另一个独立操作。完整备份恢复成功后会使台词、活动精确参数等偏好类旧草稿失效，防止再次保存时覆盖刚恢复的值；活动区域和 Host 智能授权草稿不受此重置影响。

智能设置直接选择 DSH 已配置的模型，按提供商分组，无需填写 provider/model ID 或复制凭据。首次配置优先选中网页当前会话的可用模型，其次是可用的 Host 默认模型；都不可用时需要自行选择。保存后固定使用所选模型，不改变主会话。模型与工作区目录只在打开设置或手动刷新时读取，不随状态轮询反复加载，也不调用模型。

首次配置默认勾选当前已知的全部工作区，也可切到“指定工作区”逐项选择。已有选择保持不变，以后新增的工作区不会自动加入授权；刷新后可以重新选择全部当前工作区。最多选择 100 个工作区，超过时需要缩小范围。只有明确勾选启用并保存成功后才开始理解；预选、切换模型、打开设置或预览均不代为启用。模型凭据仍由 DSH 管理。保存时撤销工作区授权会删除其已有记忆与摘要，界面会列出工作区并要求再次确认；删除单条记忆或工作区全部记忆也会清空该工作区任务本、工具事实、提醒和来源时间线，必须确认后才执行。

“显示场景”默认开启，在首页和快捷设置均可关闭。关闭后隐藏小窝、经典工作布景、外部角色背景和奇遇环境道具，并暂停非必要环境演出；人物、牌子、手持动作道具和双宠互动仍保留。开关不会清空小窝、主题或家具选择，重新开启后按保存的选择显示。小窝页的细分开关只控制小窝本身，不代替这一总开关。用户显式打开的角色或奇遇素材预览仍可单独查看，不改变实际舞台的显示设置。

活动范围新增“全屏自由活动”：网页中使用当前可见区域，桌面中使用当前显示器工作区；碰到边缘会停步或转向，工作、拖动和直接互动优先。它不会自动授权跨屏。“活动区域与回家点”可绘制矩形允许区与禁行区，保存回家落脚点；未自定义回家点时，默认回到允许区内靠近屏幕右下角的安全位置，也可随时恢复默认。散步按完整宠物占位避障，尺寸变化后重新校正；主动回家只按完整工作区和禁行区规划，允许区高度不再阻挡回家。自定义回家点由角色中心对准，边缘时任一部位到点即可。区域只保存在本设备，不随陪伴方案导入；绘图或数值修改需要保存才生效。目标不可达时停止自动移动并说明；已保存的配置损坏时也停止自动走动，等待明确修复。回家目标在完整工作区外或被禁行区阻断时仍明确报错；需要恢复时先走到安全候选点，再沿路线行走进回家点，不瞬移。工作任务和打开的设置仍优先，排队回家会明确提示关闭设置并等当前任务结束后走，不为了移动宠物取消任务。提示保留完整原因、最多占两行，可手动关闭；非进行中的提示会在 8 秒后消退，主动拖动会清除旧提示。桌面端从“设置回家点”直接进入原生设置窗口的区域编辑器。

按住宠物操作卡右上角可等比例缩放。向上或右拖会放大，向下或左拖会缩小。鼠标靠近时边角会高亮。拖动时预览，松手保存一次，取消拖动会恢复原尺寸和位置。也可在边角聚焦后用方向键微调，按住 Shift 可加大步长。网页尺寸随可视 CSS 视口计算，桌面使用原生 DIP 坐标。左侧非角色舞台仍可点击底层页面，空挥动作与布景保留完整绘制空间。

## 动作与生活

内置角色新增 32 段八帧生成序列，共 256 帧；包括散步起停、转身、摸头、喂食、玩具、小窝和管家姿态。它们与原来的 101 项动作编排分别统计；左右镜像不重复计数。完整设置中的“智能宠物新动作”可逐段预览，全部帧已完成基础显示可用检查；蓝描边与帧间透视差异仍保留，作者最终审美选择单独记录。[素材与制作记录](../assets/intelligent-pet/README.md)。

活跃程度有安静、偶尔、自然、活泼、持续与自定义六档。新安装默认「持续活动」，每段完整播放后休息 1–3 秒。举牌、旧空闲动作、新生活链和散步共用休息节奏并轮流让位。专家设置的“精确间隔覆盖”默认关闭；旧配置自定义过的散步或奇遇间隔会迁移为开启。覆盖散步有独立的首轮和后续到期时间，仍不能打断当前动作，也不推迟已经到期的普通活动。

牌面文字保持正常字形比例，优先换行，在有限字号范围内适配；超过牌面容量时显示省略号，不把整句横向压缩成细字。牌面省略不改写保存的台词；可在台词设置缩短文案。

说话频率独立于动作和消息显示模式：调整频率不会把“仅台词”改回“台词和状态”。只在事件变化时不主动换句，偶尔至少 30 秒，经常至少 10 秒；旧空闲和新生活共用台词冷却。选择不主动说台词可保留状态，用户直接互动和重要事实通知仍可回应。动作幅度按真实素材强度筛选，不声称重新绘制序列帧；外部角色没有低幅动作时保持稳定姿态，重要反馈和手动演出不受自主动作筛选限制。

普通单段序列播放完保留末帧至少 3 秒，生活链可停留更久；直接互动、重要事件和拖动能让位。安静模式不主动启动生活链。开启任务管家时，只要账本中还有运行或等待的任务，就不会安排睡眠。

“外观与生活”无需开启智能模式，提供小窝布置、三套本地装扮、成长动作解锁和真实项目收藏。浅海、月夜与花园的小床、桌灯等家具和角色共用落脚平面；局部灯光、水纹、花瓣、睡眠气息和喝茶蒸汽按动作与任务状态变化。安静陪伴、安静计时、仅重要提醒、减弱动态、打开设置、拖动或页面不可见时暂停环境动画；恢复后可继续播放，不调用模型。喂食、摸头、玩具、季节／阶段演出及双宠邀请在宠物互动菜单发起，不混在配置页中；抛球和逗鱼保持菜单展开以便继续操作。装扮是贴合角色锚点的道具层，保留尾巴和鲸鱼标志；内置角色在躺卧、睡眠或大幅互动时收起装扮。外部角色须提供相应装扮锚点，缺少锚点时不强行佩戴。

成长动作解锁默认关闭。开启后，新增的可选动作按真实主动互动次数开放：接球等动作需要 5 次，逗纸鱼、整理小床与季节演出需要 10 次，明信片与双宠分享需要 20 次；基础动作、确认和任务成功／失败反馈始终可用。关闭解锁限制后立即恢复全部可选动作。相处日记、首次相识日期与阶段只由实际主动互动记录，不因离开扣除成长；清空相处记录也会清空次数和相识日期，但不会删除任务、模型记忆或已收藏的项目明信片。模拟页面不生成真实相处记录。

季节和成长演出由开场、较长停留与谢幕组成，文字明确标注“宠物剧情（虚构）”，不冒充真实会话经历。默认由用户手动播放；可另行开启在真实成长阶段或季节变化时演出，并设置最短冷却。这不是定时演出间隔；提高活跃程度也不会反复制造阶段故事。首次打开时只建立阶段基线，不补播旧故事；工作、重要提醒和直接互动能打断演出。

双宠当前是一名受邀临时伙伴，可选择跟随主角色、内置大肥鱼或本 Host 已安装的其他角色；尚不支持数量配置。伙伴缺失时保留选择并提示，不自动下载或借用其他 Host 的角色。它只在受邀时进入同一个舞台，依次招手、传球、分享茶点和告别；身体保持各自区域，传递的是道具，不把站立贴图平移当作走路。两个角色共用同一条本地行为链和 Host 预算，不创建第二个模型调度器。每一段等待双方实际绘制后才推进，结束或被打断后副宠离开。外部角色缺少任一必要动作、双宠映射或未满足成长条件时，不启动不完整演出。

“桌面奇遇”提供纸箱、纸鱼船、钓纸鱼三种虚构小剧场，可选择种类与间隔；只在宠物舞台内播放，工作和重要提醒会打断。生活与双宠演出复用已有角色帧序列和道具，不计为额外绘制的角色动作。这些本地功能均不调用模型。

## 智能理解的范围

Host 按工作区和会话记录任务标题、最近公开回复、事件状态，以及有限的工具执行事实。工具名称、调用与结果事件、耗时、明确错误码和公开结果短摘可进入理解上下文；每个任务保留最近 6 条工具事实，一次理解只使用其中最近 3 条，每条短摘最多 360 个字符。不匹配的迟到结果不归给另一调用，结果未知会保留为未知；单个工具成功不代表任务完成。

工具参数、完整日志、任意扩展字段和问答工具的提问／答案不进入这份工具上下文。结构化结果只选已知公开字段；文本先过滤常见凭据、环境变量、编码数据和私有推理标记，再裁剪。过滤不等于能识别所有敏感业务内容，授权前仍应确认所选工作区适合交给该模型。工具文本作为资料读取，不执行里面的命令或角色要求；宠物理解本身不调用工具。

智能结果和派生摘要保留来源工作区、会话、事件及工具调用／结果引用。接收结果前检查这些来源是否仍然一致，状态变化后的旧解释不覆盖新事实；删除记忆会清理派生摘要与待用上下文。事件决定状态，模型只解释已知内容，缺失的工具结果不能补成事实。智能管家的“任务与记忆来源时间线”可按工作区、会话筛选，查看任务状态、工具调用与结果、事件提醒、模型解读和明确确认的偏好，展开来源并跳转已知会话。最多展示 Host 保留的 150 条近期记录，不重建完整聊天历史。旧记录缺少创建时间时明确显示未知；来源已变化的模型文字不作为当前进展展示。删除记忆后重新读取真实 Host 状态，旧在途读取不能把已删内容填回。

## 额度提醒

任务返回结构化的账户额度不足、上下文过长或输出上限时，大肥鱼显示对应原因；普通的限流或网络错误不会一律叫作余额不足。关闭智能、管家或记忆，仍可收到额度提醒；提醒本身不调用模型。

宠物共享预算用到至少 80% 时提醒一次；预算不够下一次请求时，发送前拦截并提醒。预算按 Host 共用，刷新、另一页面或桌面不会重复领取同一条。用量缺失时会说明估算。

## 语音与主动分享图片

开启“语音与感知”后，可在智能设置中使用以下入口。类型预设不会直接启动录音、朗读或上传。

- **Web 按住说话**：需另外勾选本次浏览器识别许可；松开、离开页面或 25 秒后结束。文字先填入输入框，由用户确认发送。浏览器语音服务可能处理音频并有独立费用，不属于宠物模型预算；不支持的环境显示原因。浏览器支持与远端识别的边界见 [Web Speech API](https://webaudio.github.io/web-speech-api/)。
- **桌面按住录音**：先在桌面设置配置本机或 HTTPS 转写端点，再明确允许本次录音。支持 Audio Transcriptions multipart 协议；仅按住时打开音频输入，松开后发送本次音频，最多 25 秒／3 MiB。文字先预览，另按确认才调用模型。服务可能独立收费；密钥只保存在本设备安全存储，不进入 Host、角色包或方案。没有配置时不会录音，也不以空开关表示可用。
- **朗读**：只选浏览器标记为设备本地的声音。可主动读任务摘要或手动问题的回复，不自动朗读后台进度。没有本地声音时不偷偷选择远端声音。
- **分享图片**：用户选择文件、查看预览并逐次确认后，发送给已授权模型。客户端缩至最长边 1024 像素；Host 限单张 1 MiB、2048 像素边长与 4 百万像素，并验证真实图片。模型必须声明支持图片。图片进入 DSH 附件缓存，仅用于本次理解，不写入宠物记忆；发送前预留共享预算，用量不足不发送。没有后台截图、连续看屏或自动读取其他应用。

录音、朗读及看图只通过本地状态事件选择角色姿态；事件不携带音频、文本或图像。停止、取消、卸载和切换 Host 时复位；旧结果不会填回新 Host 的界面。语音界面与协议检查使用受控接口，不代表已经完成真实麦克风、所选外部服务或全部平台的音频验收。截图的模型接入与已测范围见[开发状态](plans/intelligent-pet/implementation-status.md)。

## 桌面与 Host 共享

桌面经主进程认证连接到指定 Host。外观与行为使用 DSH 官方 `bigfish` 设置命名空间，角色库使用同一个 Host 角色接口，读写带 revision，不以桌面 localStorage 另存可编辑的一套配置。类型、角色和方案的切换不修改智能授权、预算或设备权限。Host 断开时，当前进程保留已确认的外观、已加载角色和普通互动；离线重新启动可用内置角色。

切换 Host 会重挂宠物和设置面板，清除旧的授权草稿、问题、录音识别文字、所选图片及确认状态。旧 Host 的截图请求会尽力取消；已发送的请求仍可能产生用量。转写请求在主进程中止，不把取消消息发到新 Host 的模型服务。

桌面任务卡的“打开会话”发布一次性 Host 导航意图，再打开这个 Host 的网页。可见且已登录的 Web 页面领取后调用 DSH 会话导航；只打开真实来源会话，不批准、重试或执行任务。意图两分钟过期，多个页面只能领取一次。

同一 Host 只授予一个网页或桌面窗口宠物显示权，其他窗口仅保留设置入口。网页每 5 秒续租，异常退出后租约最多 15 秒自然过期；正常刷新或关闭通过 `pagehide` 发送带 `keepalive` 的释放请求，新页面使用新的随机 client ID，旧释放不会误删新租约。

附近散步按转身、起步、真实行走、停步和休息串联，准备段与停步不移动窗口；缺少行走素材时不把站立图平移。主动跨屏默认关闭，开启后仅空闲且有素材时约每五分钟尝试一次，拖动、工作和重要事务让出控制。显示器坐标使用 DIP；拔插、缩放和睡醒时校正工作区并取消旧路线。活动范围提供固定、附近、较大范围和全屏自由活动；允许区、禁行区与回家点按本设备保存，跨屏仍需要单独启用。窗口放置和外观改大小使用同一份目标坐标，避免把原生 setBounds 后的过渡读数当成散步起点；“叫回来”和首次应用大小的顺序已有确定性竞态回归，仍需真实窗口与硬件验收。

窗口边缘探头只使用用户在此设备明确授权后的窗口位置和大小，不读取标题、截图或内容。Host 的桌面设置独立保存于 `$DSH_HOME/pets/dsh-bigfish/desktop/state.json`，设备授权另存本机；其他设备不会因 Host 开关已启用而自动获得窗口感知权限。macOS 如缺少辅助功能权限会显示原因，不把无数据伪装为成功感知。

当前 Mac 验证包含真实 Electron 窗口与临时 Host 契约服务；这不替代原生 DSH 组合、物理多屏混合 DPI、Windows 硬件、真实麦克风、长时休眠及签名安装包验收。运行与协议配置见[桌面说明](../desktop/README.md)。

## 用量和数据

普通动画、小窝、互动、日记与基于真实事件的任务提醒不消耗模型 token。新会话事件触发自动理解，至少间隔 120 秒，默认 20 次/日；没有新事件不理解。默认总预算 30,000 token/日，当前按 UTC 零点切日，界面明确标注。自动和手动理解共用预算；请求先预留，返回后结算，usage 缺失时保守估算，不能理解为精确金额上限。

记忆仅使用授权工作区的公开回复、事件摘要和上述有限工具事实。默认摘要保留 7 天，明确确认的偏好长期保留。删除会同时清理派生摘要与待用上下文，旧模型回复和删除前已排队的事件不会重新填回来。

账本、预算、介绍记录和收藏保存在 `$DSH_HOME/pets/dsh-bigfish/companion/state.json`，以文件锁和原子替换协调多个客户端。不要手改运行中的状态文件。

## 本地开发

```bash
pnpm install
pnpm check
pnpm test
pnpm build
pnpm preview
pnpm desktop:build
cd desktop
npm install
npm start
```

桌面端安装与平台限制见 [桌面说明](../desktop/README.md)。开发产物未签名，不应当作完整发行版分发。开发时先使用隔离的 DSH_HOME，避免覆盖日用 Host。

角色包协议见 [制作规范](pet-pack/spec.md)。本开发版支持可选的身体边界与落脚点、触摸反应、生活动作、小窝背景、语音展示和双宠动作声明。角色可以使用自己的动作 ID，通过语义映射接入调度；缺少可选能力时明确降级，旧包继续可用。装扮可按角色或逐帧提供头部、颈部和胸前锚点；动作可以声明 `unlockAt`，但五种基础回退动作不能被成长锁定。

随包的 `dsh-bigfish-pet-maker` Skill 包含这些声明、校验和本地预览说明。能力声明只选择本地素材，不授予模型、录音或截图权限，也不能携带可执行代码。向 npm 0.6.0 用户分发时，不要声明这些开发版新增的必要能力。
