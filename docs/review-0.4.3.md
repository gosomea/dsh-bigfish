## 已修复与补齐

- “空挥互动 → 关闭”不易发现，改为独立“启用鞭策动作”总开关；无法使用反应素材的角色也能关闭总偏好。
- 内置 flinch/dodge 曾可独立进入普通随机动作池，关闭鞭子仍可能看见躲闪；禁用时排除并立即重新选择。
- 外部角色带 near-miss 与 working 双标签时，反应可能被普通导演随机选中，脱离空挥节拍；near-miss 现在专用于互动或明确素材预览。
- 架构说明仍写三张图集、28 类动作、没有新增路由，现已按五张图集、29 类动作及 Host 角色库更新。
- 设置文档把通用角色包与浏览器本地编排混写，补充存储范围、备份/恢复与卸载保留数据说明。
- 速度文档混入设计目标：加载历史强制降级、快速重学、可编辑映射锚点。已改为真实实现和明确未实现的边界。
- 新增 FAQ，文档导航区分当前说明、协议版本和历史验收；Maker Skill 补充无鞭策状态的素材要求。

## 尚值得优化（本轮未实现）

1. **同一 DSH_HOME 多进程同时修改角色库的文件锁。** 目前 HostPetStore 的队列只约束单个实例；原子替换可避免半写文件，但两个 Host 同时导入/切换可能覆盖彼此的 catalog 更新。建议共享锁与读改写冲突检测，再增加双进程并发测试。普通多会话并不等于多进程同时写角色库。
2. **设置和角色库的一键备份/恢复。** 当前需分别保留角色包、Host 设置与浏览器编排；导入应先校验并提供差异预览。
3. **维护性。** UI 设置、Canvas 渲染和部分角色包模块仍有较长、较密集的函数；适合按设置分组、渲染层和纯动作策略逐步拆分，不建议为首版一次性重写全部。
4. **动作品质。** 阅读/工具/确认已有连续关键帧；喝茶、擦汗、伸懒腰等低频动作仍有单姿态加变换。继续精修独立手部/尾巴动作、姿态衔接，比堆动作别名更有价值。
5. **可选后台任务角标。** 可显示“另有 2 个任务运行中 / 1 个等确认”，同时保持当前动作不被后台抢占；默认安静，不增加反复催促。
6. **扩大兼容性验证。** 当前验证集中在本机 macOS 与指定 DSH rc；Linux/Windows、另一 DSH 版本和跨天运行仍需要真实验收。原始角色参考出处未查明，NOTICE 已披露，不能把记录存在视为素材授权已补齐。

以上是已确认的实现边界和改进建议，不将未执行事项标成已交付。最终安装与测试证据见 dist/verification-0.4.3.json。
