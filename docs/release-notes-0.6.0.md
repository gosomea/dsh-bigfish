# 0.6.0 · 新动作直接加入内置大肥鱼

原有 29 类动作全部保留，新增 72 段六帧动画直接参加内置角色轮转，共 101 类动作、18 种举牌演出。无需安装 `@next` 或选用单独的「趣味版」。

```sh
dsh plugin --profile web add dsh-bigfish
dsh --profile web
```

已有用户在任务空闲时重启 Host 并刷新页面。现有自定义角色选择、行为偏好和台词保留；使用内置大肥鱼的用户直接获得新增动作。此前手工安装的独立角色包保留在角色库，不自动删除。

新增内容包括举牌、日常陪伴、开工思考、工具执行、等待与任务结果、彩蛋和五种可关闭的非接触空挥反应。原有动作继续使用原始素材与绘制，新旧动作共用任务标签、档位、冷却和轮转调度。举牌适配展示时长，工作动作在循环边界切换，一次性动作和空挥反应保留收尾停留。安静模式、减弱动态、鞭策开关和自定义台词继续生效。

「角色库 → 大肥鱼 · 内置 → 预览」可逐个查看全部动作。插件仍支持任意扩展动作的外部角色包，附带 `dsh-bigfish-pet-maker` Skill：

```sh
npx --yes dsh-bigfish install-skill
```

验证范围与环境见 [兼容性记录](compatibility.md)，新增动作名称见 [动画目录](animation-gallery.md)。历史预览版本保留，后续使用普通稳定安装命令。

本轮在 macOS Apple Silicon / Node 24.19.0 通过 151 项单元测试、34 项 Chromium 浏览器回归及 npm DSH 0.2.0-rc.2 的 15 组隔离原生流程。原生任务使用无密钥本地提供器，覆盖安装、设置、任务反馈、并发会话、内置 101 类动作、外部角色、备份与卸载；没有付费模型调用。[验收证据](release-evidence-0.6.0.json)。
