# 设置与陪伴行为（当前版本）

快捷设置：空闲互动、动作表现、消息显示、大小、启用鞭策动作，以及完整设置入口。详细设置按用途折叠，关闭消息/空挥后隐藏对应从属控件。

- **空闲互动**：安静陪着（默认）只在首次出现时问候一次，牌子 5 秒收起、问候 8 秒隐藏，之后稳定呼吸。偶尔每 2–5 分钟、经常每 20–40 秒一次 6 秒互动。气泡与牌子使用同一调度预算。
- **空闲文字**：默认固定空闲台词库第一句；可改随机。自定义台词的“空闲等候”类同时控制气泡和牌子，牌子最多绘制前 20 字以适应画面。空台词库不举文字牌。
- **防重复打扰**：浏览器会话记录首次问候与冷却。任务、隐藏、折叠中止空闲互动；恢复后重新等待，不追赶后台漏掉的互动。完成演出后直接休息，不追加问候。
- **工作台词**：仅事件变化（新安装默认）不周期轮换；偶尔 30 秒、经常 10 秒。确认、报错、完成等关键类别不周期换话，工具事实继续更新。具体工具名与工具类别区分显示。
- **动作表现**：轻柔使用稳定小动作，自然限制高能动作与幅度并延长更换间隔，活泼开放全部动作。档位改变立即重选符合策略的动作；不影响空闲互动频率。
- **动画**：跟随系统 / 正常 / 减弱动态。减弱动态停止非必要位移、轮播、粒子和空挥，状态变化仍更新静态姿态。
- **消息显示**：台词和状态 / 仅状态 / 仅按钮。仅按钮不再泄漏状态和统计行。安静休息可只留两个控制按钮，也可选择保持消息可见。
- **启用鞭策动作**：快捷设置、完整设置和 DSH 插件设置共用的勾选开关。关闭后立即停止鞭子与配套躲闪，不再触发鞭声音效；正常工作、工具、完成和空闲动作继续。刷新、换会话、换角色后仍保留。开关即使在当前角色不支持鞭策时也能操作，避免切回其他角色后意外恢复。重新开启保留上次催更/随速度模式；下方“鞭策节奏”选择模式。轻中强预设，精调在高级设置。动作完整播放，频率上限是调度限制，不承诺超过动作本身时长的次数。音效默认关闭。
- **外观**：角色大小显示百分比；字号同时影响台词和状态；透明度不再影响打开的设置面板；“场景”改名“布景”。
- **任务结束**：简短庆祝 / 仅完成提示 / 直接休息。
- **预览**：完整设置中的“预览当前效果”使用实际动作策略、消息模式和空闲调度，可快进 5/30/120 秒。台词类别预览和独立演示页动作目录用于指定素材预览，仍遵守动作档位和减弱动态限制，不消耗实际宠物的首次问候。角色库明确点选某个躲闪素材时允许查看该素材，但不显示鞭子，也不改变日常鞭策开关。
- **扩展**：原生与浮层完整设置都可导入动作包。最近观察到的 20 个工具名称可选填规则，仍支持手写精确/前缀规则。可替换角色包由 Host 保存；内置 JSON 动作编排、速度历史和空闲冷却保存在浏览器，详见 [存储说明](faq.md)。主要设置由 dsh Host 同步。

## 备份与恢复

完整设置新增“备份与恢复”，统一导出角色、偏好、台词、工具规则和本地动作编排；恢复前预览变更，保留现有角色。限制与失败处理见 [说明](backup-and-storage.md)。

## 迁移

偏好版本 1 自动解码为版本 2；首次写入使用同一 Host revision 原子写入完整迁移值。旧自定义台词、规则、大小、声音、动作档位、说话档位等保留；新空闲策略默认安静。原说话档位 0/1/2 对应事件变化/30 秒/10 秒，不再控制空闲轮换。

旧气泡开关组合规整为新的显示语义，避免全部关闭后状态反而出现。恢复显示与行为默认不清空自定义台词或工具规则。迁移不改原始历史、模型请求和任务数据。

## 验收范围

纯逻辑测试与浏览器虚拟时钟验证十分钟安静空闲、频率上下界、关键提示、刷新/后台/折叠、防重播、动作档位切换、减弱动态、明确关闭空挥、消息三模式及预览。设置持久化测试覆盖旧配置迁移与 revision。原生安装测试使用隔离 Home 和无密钥本地模型。

“疲惫积累周期”与速度估算等保留在高级设置；疲惫周期 40% 起仅使擦汗进入可选池，并非定时保证触发。随机互动次数和实际渲染性能依赖浏览器可见性，测试报告不等同于跨平台长时间运行保证。
