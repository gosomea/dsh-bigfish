# 0.6.0-next.1 · 大肥鱼趣味版

本版发布到 npm `next`。提供原始萌化大肥鱼的趣味角色包，在完整设置的角色库直接预览或“使用趣味版”，无需另外下载。原有角色选择、行为偏好和自定义台词保留。

## 动画与台词

- 72 段新绘制演出，每段六个关键姿态，共 432 个新姿态；五类基础回退复用已有美术。角色包合计 77 个动作、452 个帧引用。
- 13 种举牌小剧场、尾巴日常、读书与搜索、工具控制台、测试巡检、绘画调色、并行分篮、完成收工和可关闭的空挥反应。
- 举牌、日常和彩蛋按家族选择，减少大量同类素材挤占轮转；彩蛋至少隔十分钟。
- 一次性空闲演出可声明保持帧，适配 5–30 秒互动展示窗口，保留取道具和收好动作。
- 角色包可用动作 ID 定义台词，按当前画面选择；用户自定义类别与空数组静音仍优先。
- 工具过程与真实结果分开；成功仅响应当前会话明确完成。开工、重试和空挥专属动作不混入普通工具动作池。

## 安装

```sh
dsh plugin --profile web add dsh-bigfish@next
dsh --profile web
```

任务空闲时重启并刷新页面，然后在“完整设置 → 角色库”选择“使用趣味版”。Skill 也可更新：

```sh
npx --yes dsh-bigfish@next install-skill
```

安装器仍保护用户修改的已有 Skill；内容不一致时请先备份旧目录或使用其他技能目录。

成年版保留原有素材，新增 72 段本轮用于原始萌化版本。普通待机依然安静眨眼，所有小剧场均遵守空闲互动预算与减弱动态设置。

## 验收范围

macOS Apple Silicon、Node 24.19.0：147 项单元测试、34 项 Chromium 浏览器测试、DSH `0.2.0-rc.2` 的 15 组原生流程通过。原生流程使用隔离 Home 和本地无密钥流式提供器，验证真实 Host 会话生命周期，没有付费模型调用。旧版 DSH 和 Linux 的历史覆盖列在兼容性记录中，本轮没有重复所有旧环境。

趣味版图集按协议检查为 29,622,272 解码像素、432 个新姿态、13 个有牌文锚点的举牌动作。原有用户角色不会因升级自动替换；安装后请主动选择趣味版。
