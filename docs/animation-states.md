# 大肥鱼动作与状态索引

本页对应 `0.7.0-next.1` 内置大肥鱼。按运行时素材入口共 **133 项**，其中 **29 类经典动作、72 段扩展动画、32 段智能宠物动作**。同名动作可能有不同版本的素材，例如经典喝茶和新版八帧喝茶。环境特效、复用这些素材的小剧场和外部角色包另算。

经典与扩展动作可在「完整设置 → 角色库 → 大肥鱼 · 内置 → 预览」查看。72 段扩展动画的名称、ID 和标签见[动画目录](animation-gallery.md)。该目录末尾的五个基础回退属于原独立角色包，内置大肥鱼使用经典动作作为回退，所以不重复计数。

## 任务状态与可用动作

表中列出内置角色的优先动作池、经典姿态或按事件接管的八帧动作。满足强度、冷却、素材和设置条件后才会播放。正在执行的工具标签可以细化思考或输出的动作。优先池为空时会回退到所属状态的通用动作。

| 状态 | 优先动作与回退 |
| --- | --- |
| 空闲待机 `idle` | 眨眼、呼吸和轻微摆尾。到空闲互动时间后，从五种经典举牌及[举牌等你](animation-gallery.md#举牌等你--13-段)、[日常陪伴](animation-gallery.md#日常陪伴--12-段)、[彩蛋](animation-gallery.md#彩蛋--6-段)的等候动作轮转。散步和生活演出也参与空闲轮转。 |
| 已提交，等首段输出 `awaiting-output` | 挽袖开工。经典候选有眨眼、抱尾、阅读、回头、手忙脚乱、打勾、踉跄站稳、探头、喝茶。 |
| 思考 `reasoning` | 拼起思路、草稿演算、整理便签、算盘推演、观察沙漏、画一张路线图、齿轮咔哒转；经典阅读。任务管家还可播放八帧「思考」。 |
| 输出 `generating` | 左右手交替打字、便签打字、尾巴打拍子、蘸墨写草稿。工作场景可按压力和疲劳轮到小碎步、跑步机、擦汗、回头、手忙脚乱、打勾、踉跄站稳。 |
| 等下一段输出 `streaming-gap` | 沿用输出的打字和工作动作池，短暂停顿时保持当前工作姿态。 |
| 调用工具 `tool-running` | 根据下表的工具语义挑动作；无法分类时使用通用工作池，经典工作坊有修理、擦汗、回头和伸懒腰。 |
| 等待确认 `waiting-user` | 伸手等待、把选择递给你、轻摆提示铃、递来确认信。管家提醒可用「递出确认卡」。 |
| 重试 `retrying` | 清理后再试、擦掉重画；候选不足时回退到问题动作池。 |
| 连接中断 `disconnected` | 戴眼镜排查、检查小接线、困惑地图；经典回退为阅读检查。 |
| 完成 `completed` | 经典庆祝、抱尾、鞠躬、挥手，或鲸鱼验收章、开心收工、交付小礼物、纸花庆祝。管家收工链可用合上任务本 → 完成鞠躬 → 递出明信片。 |
| 取消 `cancelled` | 回归待机，经典结束姿态包括眨眼、抱尾和叹气。 |
| 中断 `interrupted` | 回归待机，使用与取消相同的经典结束姿态。 |
| 失败 `failed` | 戴眼镜排查、检查小接线、困惑地图；经典阅读检查。管家可用检查失败 → 合上任务本。 |
| 被阻断 `blocked` | 使用问题动作池，搭配对应状态文案。 |
| 达到限制 `limited` | 使用问题动作池。收到明确的额度、上下文或输出上限事件时显示对应提醒。 |
| 结束原因未知 `unknown-end` | 使用问题动作池，保留未知状态。 |

### 工具与工作语义

| 工具语义 | 对应动画 |
| --- | --- |
| 读取文件 | 阅读夹书签、书堆找答案；经典阅读翻页 |
| 搜索 | 放大镜找线索；经典探头 |
| 编辑 | 铅笔修改；经典打字 |
| 命令 | 启动小控制台；经典修理 |
| 测试 | 测试巡检；经典阅读检查 |
| 网页 | 望远镜看网页；经典阅读 |
| 图片生成 | 调色画画；经典打字 |
| 导出文件 | 整理交付包、打包小行李箱；经典打勾 |
| 并行任务 | 多任务分篮；经典小碎步 |
| 后台任务 | 看守小生态箱；经典稳定站姿；管家可用分拣会话卡 |
| 子代理协作 | 小导演带队；经典挥手 |
| 其他工具 | 通用工作池包含上表工作素材及思考、书写动作；经典修理可作为工具动作 |

空挥反应另走专用节拍。可用缩肩、侧躲、保住茶杯、收好尾巴、深吸气、扶眼镜和稳住节奏。关闭鞭策或减弱动态时，回归普通任务反馈。

## 32 段智能宠物素材

每段八帧。动作可被多个演出复用，以下按素材目录分组。

| 分组 | 完整清单 | 出现场景 |
| --- | --- | --- |
| 身体与移动 · 8 | 散步、减速停步、迈出第一步、转身、踮脚、边缘探头、收好尾巴、叫回来 | 平时走动、到达屏边和主动回家。主动回家走「起步 → 行走 → 停步」，点「停止回家 ×」可撤销排队或原地停下。 |
| 主动互动 · 8 | 摸头、接球、逗纸鱼、喝茶、分享饼干、梳尾巴、招手、指向卡片 | 主动触摸、喂食、玩具、打招呼，也可用于双宠、故事和奇遇。 |
| 生活 · 8 | 坐下、睡醒、入睡、伸懒腰、躺下、整理小床、整理书桌、点灯 | 闲暇坐下伸懒腰、整理书桌、点灯、整理床铺和入睡后醒来。小窝与家具链受场景开关约束。 |
| 管家 · 8 | 分拣会话卡、递出确认卡、合上任务本、递出明信片、阅读屏幕、思考、完成鞠躬、检查失败 | 多会话、确认、任务结果、按住说话与主动分享后的反馈。 |

工作和重要提醒可以接管空闲演出。普通动作按完整循环或收尾切换。「持续活动」缩短动作完成后的休息间隔，播放速度由对应动作决定。外部角色使用自己的标签、素材与回退；低强度、减弱动态、关闭能力或缺少素材都会缩小实际候选池。

素材与规则依据为[经典场景清单](../packs/classic/manifest.json)、[扩展动作清单](../examples/bigfish-playful/animations.json)、[八帧素材目录](../assets/intelligent-pet/catalog.json)、[任务状态](../src/contract/types.ts)和[动作调度器](../src/pet/director.ts)。
