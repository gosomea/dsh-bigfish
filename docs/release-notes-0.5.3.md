# 大肥鱼 0.5.3 · 空闲互动更自然，设置更清楚

## 安装 / 升级

```sh
dsh plugin --profile web add dsh-bigfish@0.5.3
dsh --profile web
```

如果 DSH 正在执行任务，请等任务空闲后再重启并刷新页面。主要设置、自定义台词和已导入角色会保留。

## 本次更新

- **五档空闲频率和自定义间隔。** 可选安静、偶尔、自然、活泼、持续活动，或设置 1–600 秒休息区间。间隔从一段动作完整展示之后计算，浮层会显示当前状态和下一次互动倒计时。
- **举牌真正停在举稳姿态。** 旧版会很快播到放下牌子的末帧，视觉上像长期站立。本版延长举稳的中段，最后再自然放下；可选择多举牌、均衡轮换或完全不举牌。
- **后台与任务收尾不再打乱轮转。** 页面隐藏、折叠和重新挂载保留原等待期限；取消和中断提示 4 秒后回到空闲，错误和等待确认仍保持明确状态。
- **设置语义与生效条件统一。** 消息显示补齐“仅台词”，减弱动态会说明暂停原因并禁用不适用的节奏项，外部角色隐藏内置角色专属配置，手动速度模式明确不使用历史基准。
- **连续调节也能可靠保存。** 自定义间隔上下界按 Host 最新确认值串行联动，刷新后保留；新增工作台词最短停留设置。
- **内置与外部角色行为一致。** 修正外部角色的空挥频率上限与总开关；角色包仍可提供比内置大肥鱼更多的动作。

## 默认节奏

新安装默认“活泼陪伴”：一段动作展示约 12 秒，随后休息 5–10 秒。气泡最多显示 6 秒。提高互动频率不会提高动画帧率，也不会快速切断动作。

## 验证

- 134 项单元测试通过。
- 32 项浏览器完整回归通过；保存逻辑调整后相关 6 项浏览器回归再次通过。
- 使用隔离 DSH 从 0.5.2 升级到 0.5.3，15 项原生检查通过；自定义台词、角色包、角色选择和主要偏好均保留，未调用付费模型 API。
