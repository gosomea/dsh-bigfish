# 按模型自适应的速度反馈

当前实现已通过 20/100/400 合成轨迹及原生流测试，基线持久化与模型配置身份已接入。实时计数仍为估算，精确 tokenizer 未接入；具体实现参数以 src/domain/config.ts 为准。

## 1. 计数口径

当前使用 weighted-codepoints-v1 估算（界面标 ≈）：CJK 字符约 1、普通字符约 0.25、补充平面字符约 1。TokenCounter 接口允许后续接入精确增量或匹配 tokenizer，但当前发行版未接入；chunk 数和网络包数不能直接标成 token。

匹配 tokenizer 不保证可以逐个 chunk 分词后相加（跨 chunk 边界可能合并），应有增量策略或按有界缓冲重新计算；控制计算频率与内存。无法经济地精确分词时选择明确的估算策略，不制造精确数据。

默认记录 reasoning、text、tool-call arguments 三条模型生成通道；工具返回文本从不计入。UI 可选择推理是否影响表演，计数通道集合进入 modelKey。无法观测隐藏推理时标为不可观测，最终 usage 不反推实时曲线。

provider 的 outputTokens 与可见通道未必同口径。只能在范围一致时校准估算误差，不能将 usage 总数分摊到正文并宣称精确。失败 attempt 已实际生成的数据可用于消耗统计，但只用符合质量条件的窗口学习正常基线。

## 2. 模型身份

modelKey = provider/endpoint 配置标识 + 实际或可见模型标识 + reasoning 配置 + 计数通道 + 计数方法/版本。

同名模型跨端点分桶，模型切换立即切换基线；未知实际模型时按可见配置并显示依据。endpoint 不包含凭据、URL 认证信息或敏感 query。模型标签复用造成的长期性能变化由缓慢适应和手动重置处理。

## 3. 当前速度与长期基线

当前速度采用最近 W=3 秒有效生成窗口的 token 增量/观察秒数，并使用时间相关 EMA：alpha = 1-exp(-dt/tau)，tau=1 秒。不是“从任务开始到现在”的平均速率。初始观察不足时标低置信，不用首个包除以极小时间制造尖峰。

窗口内正常包间隔保留，不能只计算发生 chunk 的瞬间。明确工具、审批、重试、断连结束该生成区间；无 chunk 超过建议 3 秒进入 streaming-gap，原因仍可能未知。进入 gap 后冻结基线学习、逐步降低显示速度；超过宽限后只允许温和催促上限，首段输出前不按 0 tok/s 惩罚。

网络单次成批到达引起的峰值通过平滑/档位滞回处理；没有额外证据时无法分辨所有网络抖动和服务降速，不声称能测到服务端真实解码速度。

长期基线使用非重叠有效窗口，避免把 5 Hz 滑动窗口当成独立样本。最多保存 120 个窗口的稳健统计，使用 P25/P50/P75；当前 attempt 内冻结参考基线，仅在合格区间边界缓慢更新候选值。单个 attempt 样本贡献有上限，防止长任务独占历史。

重要：慢速不是一概排除的“坏样本”。当前 attempt 的异常低速不立即重定义正常水平；多段/多次调用持续处于新水平时逐渐适应。已有至少 12 秒有效样本时，每次结算的中位数变化限制为前值 ±10%；当前没有额外的快速重学检测，可通过设置手动重置模型速度记录。

## 4. 冷启动与置信度

- 首次模型无基线：中性工作演出，显示“学习速度中”。
- 累计至少 12 秒、至少 4 个非重叠合格窗口：建立 provisional 基线；异常/包批量特征可推迟学习。
- 有效观察至少 60 秒且覆盖至少 3 个 attempt：可进入 mature；不是只由窗口数量决定。
- 有历史：恢复有效数值样本与原置信度依据，超过 30 天的记录丢弃；当前未实施按年龄连续衰减或加载后强制降级。
- 短任务结束不强求完成校准，不能使用演示样本补足。
- 计数不可用：保留状态、时长与动作，隐藏相对速度驱动，提示原因。

置信度 c∈[0,1] 同时控制相对速度的影响权重；即使样本偶然异常，也不会从冷启动直跳极限档。

## 5. 初版映射

令 r = smoothedRate / baselineP50，baseline 有效且大于 0 才计算。r 的显示可以保留实际值，动画输入有界。ratio 为首版主要信号，成熟分位范围用于显示和噪声带；不以分位排名完全代替比例，避免抖动很小的模型稍慢就进入极限档。

当前固定映射锚点，之间线性插值；界面可设置模式和手动基准，未开放编辑锚点：

| r | 催更压力 p | 节奏活跃度 a |
| --- | --- | --- |
| 0.25 | 1.00 | 0.05 |
| 0.50 | 0.75 | 0.20 |
| 0.80 | 0.35 | 0.40 |
| 1.00 | 0.15 | 0.55 |
| 1.25 | 0.05 | 0.75 |
| 1.50 及以上 | 0.00 | 1.00 |

冷启动中性驱动 n=0.15；最终速度驱动为 c*p+(1-c)*n（催更）或 c*a+(1-c)*n（节奏）。手动速度模式使用用户目标为 baseline，但仍需要有效短窗。

可选时长催促 d = clamp((activeWorkElapsed-referenceDuration)/referenceDuration, 0, 1)。启用时 pressure = clamp(speedDrive + timeWeight*d, 0, 1)，timeWeight 默认建议 0.25；默认关闭此项。非挥鞭状态无条件覆盖输出为 0。

疲惫 fatigue 可使用 clamp(activeWorkElapsed/fatigueHorizon, 0, 1)，独立于 pressure。场景导演将 fatigue 转成小剧情而非持续惩罚。

压力映射到配置范围内的空挥频率；建议最高 2.2 Hz。频率变化做 slew 限制（如每秒最多变化 0.6 Hz）。档位采用 0.05 滞回、至少 1.5 秒保持；取消/失败/等待等控制状态立即退出，不能被最短保持规则拖延。

## 6. 验证原则

将同一相对轨迹乘以 20、100、400 三个基准，成熟模式下的 pressure 和场景档位应相同（数值容差见验收）。基线降低、模型换端点、未知计数、隐藏推理、重试、工具等待必须单独测试。

记录测试用 currentRate、baseline、confidence、pressure、state 曲线以观察变化，不用人工盯 UI 判断算法正确性。精确合成轨迹与真实估算轨迹分开验收，后者不宣称同等误差保证。

## 7. 多会话与关闭鞭策

只采样当前打开会话的新输出。切换会话清空短窗和观察计数，恢复任务状态与墙钟时长，不重计历史文本；已结算的模型速度历史仍按模型分桶复用。未观察到的后台输出不累计。关闭“启用鞭策动作”仅停止相关演出和声音，速度统计、模型学习及正常工作动作保持工作。
