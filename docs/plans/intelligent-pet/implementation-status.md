## 保留的智能与数据边界

智能模式默认关闭。类型、装扮、方案导入不能开启模型、麦克风或截图权限。普通动画、小窝、互动、故事、双宠及本地任务提醒不调用模型。

Host 负责按工作区与会话隔离的任务事实、单次介绍、展示租约、通知原子领取、记忆、过时结果丢弃和用量。支持真实问答等待、多个审批、子代理来源；不把历史空闲猜成任务完成。不同客户端不会重复理解或计费。

默认共享预算 30,000 token/UTC 日、自动至少间隔 120 秒、每日最多 20 次。自动、手动和图片理解都先预留预算；usage 缺失时保守估算。预算达到 80% 或不足下一次请求时直接提醒。DSH 结构化账户额度、上下文及输出上限错误也直接提醒，关闭管家或记忆仍可收到；不把所有 429 当余额不足。

图片先选文件、预览和逐次确认，Host 验证真实图片、授权、模型模态和预算；仅本次理解，不写宠物记忆。没有自动看屏。桌面录音只在明确同意后按住采集，松开后发送给用户配置的转写服务，文字先预览；语音服务费用独立，不混入模型 token 预算。没有常开监听。
