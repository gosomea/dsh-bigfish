# 大肥鱼智能宠物交付计划

用户批准范围：八组能力、七种预设与自定义、默认关闭的智能模式、Host 统一账本与预算、macOS / Windows 独立桌面。全能型只有全部验收后才标为完整可用。

## 阶段与门禁

1. 配置与身体：独立预设、配置差异、命名方案、能力限制、统一行为调度、移动边界、互动；32 段新动作须真实制作和逐段验收。当前 256 帧已完成基础显示可用检查，作者最终审美确认单独保留。
2. 管家与智能：Host 来源账本、一次介绍、明确启用、摘要权限、记忆删除、预算预留、过时结果丢弃、多客户端去重。
3. 桌面：独立 Electron、透明与点击穿透、托盘、多屏、离线互动、展示所有权。
4. 完整生活：小窝、收藏、真实经历、明确虚构故事、桌面奇遇、双宠。
5. 语音与感知：按住说话、主动截图、明确授权的窗口几何。
6. 整体验收：八组能力、两平台实机、签名、公证、长时运行、录屏、README 与制作 Skill。

## 不可改变的边界

- 模型开关、凭据、授权工作区和费用上限不进入可分享方案。
- 本地活动、普通模式、没有新事件时的额外模型调用为零。
- 任务状态由事件决定，模型不能批准、重试、发消息或执行代码。
- 不读取隐藏推理，不后台截屏，不常开麦克风。
- 单一 Host 负责模型请求、预算、介绍记录和展示协调。
- 缺少行走素材就原地活动，不能平移站立图冒充走路。
- 不改动用户正在运行的 3080 Host；先隔离验证。保留已有备份目录。
