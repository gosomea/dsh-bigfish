# 大肥鱼设置体验优化方案

日期：2026-09-17。审查基线：v0.1.4。状态：已在 v0.2.0 实施核心设置与行为优化。实现及验收范围见 ../../settings-v2.md。

## 结论

保留丰富素材，同时将“动作表现”“空闲互动”“工作提示”分开控制。默认空闲安静陪伴，工作发生变化时提供有用提示。设置必须对应可观察行为，不能只改名字。

本次依据源码审查。此前的设置保存测试只证明值能够保存与同步，不能证明每个档位视觉差异充分。本方案不声称已对所有设置逐项完成运行时验收。

## 现有设置逐项审查

| 设置 | 当前实际行为 | 判断与处置 |
| --- | --- | --- |
| 显示大肥鱼 | 隐藏浮层并解除当前会话绑定 | 保留总开关；关闭后仍能从 dsh 插件设置开启 |
| 动作丰富度 | 0 档主要简化输出中的姿态；空闲动作仍轮换。1/2 档共享动作池和调度，2 档主要增加高压力汗滴 | 重做为“动作表现”，必须控制动作池、幅度、帧动画和特效；空闲频率单独控制 |
| 减少动态效果 | 抑制位移、连续帧、空挥及部分特效，但 Director 仍选取新动作/场景 | 保留无障碍能力并修正；跟随系统时明确提示；各状态都不出现非必要轮播或跳变 |
| 说话频率 | 同类台词轮换下限为安静 60 秒、适中 15 秒、活泼 7 秒；状态变化仍可换台词 | “安静”不是不说话，且不控制举牌。拆为闲置策略与工作台词策略 |
| 普通台词停留 · 秒 | 实际是最小切换/合并门槛；轮换间隔取 max(此值, 档位间隔)，范围仅 1–10 秒；不控制隐藏时间 | 从普通设置删除。内部保留防闪烁门槛；需要时在高级设置叫“提示最短显示时间”，与轮换、消失独立 |
| 台词分类/列表 | 可覆盖气泡各类随机台词；空列表关闭该类；不影响牌子文字 | 保留在“自定义台词”；每类明确作用范围，空闲气泡和牌子共用配置策略 |
| 举牌文字 | FishCanvas 注入四条本地化文案，renderer 按素材帧组选择；没有用户设置 | 新增固定文字/自定义多句，与空闲互动策略联动；动作帧不能决定台词何时变化 |
| 显示消息气泡/显示宠物台词/显示活动说明 | 三开关组合复杂；消息关闭后仍有控制条及状态，当前 (!enabled || bubbleStatus) 还会使双关闭时重新出现状态 | 合并为“消息显示：台词和状态 / 仅状态 / 仅按钮”，明确显示结果 |
| 显示工具名称/文件短名 | 控制状态详情以及台词变量中的工具/文件信息；工具分类仍会显示 | 放到展开的“显示内容”；增加说明：工具类型与具体名称有区别 |
| 显示速度与用时 | 工作时显示，空闲隐藏 | 保留在“显示内容” |
| 气泡宽度/文字大小 | 影响台词卡布局；状态行与按钮目前使用固定字号，不跟随 bubbleFont | 宽度移至外观细节；“文字大小”要统一影响台词/状态，按钮保留可点击尺寸下限 |
| 角色大小 · px | size 为比例参数，实际浮层宽度为 340×size/180，并非标称角色像素宽度 | 改为百分比或“小/中/大”，不要以错误 px 含义展示 |
| 透明度 | 对整个浮层生效，包含按钮及弹出的设置 | 默认仅作用角色和消息；打开的设置保持正常对比度；放外观细节 |
| 场景/跟随任务 | 手动 scene 只替换布景，动作选择仍跟随状态 | 改名“布景”，提示“固定背景，动作跟随任务”；不要让用户误以为锁住了全部动作 |
| 互动模式 | 催更：相对速度越慢压力越高；节奏：相对速度越快越活跃 | 用完整短句解释，加入明确“关闭空挥”选项 |
| 催促强度/最高空挥频率 | 强度同时缩放压力和频率；最高频率又限幅。完整挥鞭至少 0.55 秒，2.2 次/秒并非可保证的视觉次数 | 普通设置合为“空挥节奏：轻/中/强”；内部调度完整动作，不把不可达数值暴露成承诺；精调放高级 |
| 按模型自动校准/手动目标 | 切换历史模型基准或手动基准，影响相对速度反馈 | 自动适配默认开；手动基准移高级，仅手动模式显示 |
| 空挥音效/音量 | 仅空挥时播放，需要浏览器音频手势；关闭音效时隐藏音量 | 默认关闭；保留，空挥关闭时禁用相关项；说明浏览器可能需要先点击角色 |
| 计入可见推理输出 | 改变计数通道/模型基准标识并重新绑定 | 高级；说明只影响速度估算，不改变 dsh 推理行为 |
| 记住模型速度 | 本地持久化基准；关闭时清空当前学习及本地记录，但运行期间仍可学习 | 高级；改“跨会话记住模型速度”，说明关闭后当前运行仍会学习 |
| 速度平滑窗口 | 调整速度估算窗口 | 高级；改“速度变化响应：稳一些/均衡/灵敏”，或保留秒值并解释用途 |
| 长任务额外催促/参考任务时长 | 超过参考有效工作时长后增加压力，默认关闭 | 高级且依赖空挥启用；改“工作较久时加强催促”，明确不会让模型变快 |
| 疲惫增长时长 | 满量程时间；默认动作包擦汗类在 fatigue>=0.4 时进入可选池，不保证届时出现 | 普通设置删除；高级改“疲惫动作”，说明概率与时间；不把满量程当首次触发时长 |
| 完成演出时长 | 完成后切回 idle 的时长 | 放“任务结束后”；可选简短庆祝/只提示/不庆祝，时长作为展开项 |
| 重学当前模型/清空速度记录/恢复默认 | 分别影响当前基准、全部基准、全部偏好 | 归“高级与重置”，明确范围；分区恢复默认，尽量不误删自定义台词 |
| 动作包导入/恢复 | 浏览器本地持久化，元数据引用内置图集；当前入口位于浮层设置，原生完整设置没有对应入口 | 移到原生与浮层共用的“素材与扩展”；明确作用范围、资源限制 |
| 工具专属规则 | 精确名或尾部 * 匹配，映射工具类别/显示名称 | 从主设置移到“工具与扩展”；简易模式提供最近观察到的工具供选择，手写规则折叠 |
| 台词动作预览 | 按选择的类别强制选动作，但快照是 idle，不代表真实工作上下文；例如安静档对输出的简化在这里看不到 | 重做上下文一致的预览：选场景、模拟速度、虚拟时间；显示“预览中”，不触发真实工具 |

证据入口：src/client/renderer.ts、src/domain/director.ts、src/domain/speech.ts、src/client/ui.tsx、src/client/dialogue-view.tsx、src/client/dialogue-settings.tsx、src/client/controller.ts、src/contract/preferences.ts、packs/classic/manifest.json。

空闲动作目前按动作持续时长选下一项，常见约 2.2/4/6.5 秒；richness 不进入 Director 的动作选择。减少位移或关闭气泡不能解决举牌轮换。

## 新的用户界面

浮层快捷设置只保留：

1. 空闲互动：安静陪着 / 偶尔互动 / 经常互动。
2. 动作表现：轻柔 / 自然 / 活泼。
3. 消息显示：台词和状态 / 仅状态 / 仅按钮。
4. 角色大小。
5. 空挥：关闭 / 慢了催一催 / 跟着速度动。
6. 完整设置入口。

完整设置分组：陪伴与打扰、消息内容、外观与动作、空挥互动、自定义台词、工具与扩展、高级与重置。高级和扩展默认折叠。相关开关关闭后隐藏无效的从属选项，并说明当前有效设置。

不要再用两处同名“安静”分别表示动作和台词。三个维度各有边界，修改一个不偷偷重置其他设置。

## 1. 空闲互动（解决当前主要打扰）

| 模式 | 行为 |
| --- | --- |
| 安静陪着（推荐默认） | 页面首次展示时可举一次“我在等哦”，约 5 秒后收牌；问候气泡约 8 秒后隐藏。之后仅固定休息姿态的轻微呼吸/眨眼，不轮播等候台词、不周期性举牌、不反复换场景 |
| 偶尔互动 | 保持安静姿态为主，每 2–5 分钟随机一次短动作或问候；一次最多 6 秒；动作和消息共用冷却，避免接连打扰 |
| 经常互动 | 每 20–40 秒一次小互动，丰富动作池随机选择且避免重复；大部分时间仍为持续基础动作；高级可调间隔但有防闪烁下限 |

附属项：首次展示时打招呼（默认开）、空闲举牌文字（固定一句/随机多句）、空闲时隐藏消息卡（仅隐藏文字，保留按钮）。固定一句默认“我在等哦”；用户自定义多句不意味着必须频繁轮换。

边界：任务完成先执行完成提示，随后直接进入安静休息，不紧接着再问候。切换会话、刷新历史、后台恢复和重连不重复触发问候。浏览器后台不累计“欠下的动作”，回前台不连播；新提交立即终止空闲互动。等待确认不是空闲，不能套用空闲隐藏策略。

首次问候按浏览器会话记录，不按每个 renderer 挂载记录；同时保存下一次允许互动时间，避免刷新/折叠展开绕过冷却。系统减弱动态开启时不播放首次举牌动画。

## 2. 动作表现（真正有差别）

| 档位 | 动作选择与幅度 | 特效 |
| --- | --- | --- |
| 轻柔 | 各状态使用少量稳定姿态，轻微呼吸/眨眼/手部变化；无跳跃、奔跑、探头摇晃；同状态不随机切换大动作 | 无粒子；如用户开启空挥，使用轻微对应反应 |
| 自然（推荐默认） | 保留与任务对应的打字、阅读、修理、伸懒腰等；幅度中等，大动作有冷却 | 少量必要反馈 |
| 活泼 | 全部扩展动作进入可选池；更多姿态、尾巴、躲闪和跳跃，幅度更明显 | 汗滴、速度线、庆祝粒子 |

空闲互动策略决定何时允许表演；动作表现决定被允许表演时怎么动。安静陪着+活泼表示工作时活泼、闲置时安静，不能因活泼档重新开启闲置轮播。

独立无障碍选项“动画：跟随系统 / 正常播放 / 减弱动态”。减弱动态优先于动作档位；所有状态与预览均禁止非必要轮播、位移、粒子和空挥；任务变化时仍能更新静态姿态和必要状态。界面明确展示当前因系统偏好而生效的限制。

## 3. 工作提示（信息有用，台词克制）

工作台词策略：

- 仅事件变化时（推荐默认）：新任务、进入工具类别、等待确认、失败、完成时换一句；相同状态不按时间主动换句。连续同类工具在短窗口内合并，避免每读一个文件就重新招呼。
- 偶尔说一句：工作持续时，额外台词间隔至少 30 秒。
- 经常说一句：工作持续时，额外台词间隔至少 10 秒。

状态事实独立更新：文件名、工具名、并行数量、进度仍反映最新事件；详细状态切换做短合并处理，保留最新值，不积压排队。等待确认、报错具有更高优先级，清楚显示并停留到解决；同一错误不重复提醒。完成提示一次性展示；长期静默时无需反复刷“完成”。

显示模式决定最终是否渲染台词/状态；即使“仅按钮”也不擅自恢复消息，重要提示由 dsh 本身承担，宠物可使用简洁状态点。

台词与举牌改用同一内容库和空闲调度预算；两者可选择显示位置，但不各自维护一套不受控计时器。动作里的素材帧只负责牌子位置，不再隐含文案切换。

## 推荐默认组合

空闲安静陪着；工作仅事件变化时说话；动作自然；空挥保持用户当前选择；首次问候只一次；音效关闭；自动适配模型速度；工作显示台词、状态和速度。素材数量保留，丰富度通过用户选择的场景和互动策略呈现。

## 配置迁移

新增显式配置并版本化迁移，旧值仍可读取。保留用户自定义台词、工具规则、模型基准、位置、大小、声音和开关。旧 richness 0/1/2 映射轻柔/自然/活泼；旧 talkLevel 映射新的工作台词策略，不映射空闲举牌策略，因为过去根本没有相应开关。旧 bubble 开关组合映射确定的显示模式，移除“关闭后反而显示状态”的路径。

本用户已明确反馈空闲烦扰，实施时默认选择安静陪着。对普通升级用户，使用迁移后的明确默认并提供一次简短说明，不能因值等于旧默认就武断判断用户从未主动选择。不要每次升级重新套用推荐方案。

Host schema、解码器、UI 与迁移同时交付。通过现有 Host 设置持久化；浏览器位置、空闲冷却记录仍按本地作用域保存。验证实际 dsh Host 对新 schema 的加载；如需要重启，先确认没有运行任务，不能打断用户工作。

## 实施顺序与验收

第一步：统一空闲调度、台词和举牌预算；提供安静陪着/偶尔/经常选项。先验收 10 分钟安静空闲：首个可选问候结束后，无新台词、举牌或场景轮播。

第二步：动作表现接入真正的候选动作池、幅度、冷却和特效；减弱动态贯穿全部状态；三个档位在同一模拟任务中可直接对比。

第三步：设置分组、命名、条件显示和迁移；预览接入与实际宠物相同策略，支持 5 秒/30 秒/2 分钟虚拟时间，不依赖用户一直盯着看。

第四步：原生 dsh 回归与交付。需要行为断言而不仅是设置值断言：

- 安静空闲 10 分钟，偶尔/经常符合对应互动区间；暂停、后台、刷新和会话切换不制造重复问候。
- 相同工具连续开始/结束时状态正确但不刷屏；等待确认、失败、完成不被空闲提示覆盖。
- 三档动作候选、位移范围、重复冷却和特效均有明确差别；所有状态遵守减弱动态。
- 修改工作台词频率不改变闲置策略；修改动作表现不重新开启空闲轮播。
- 仅状态/仅按钮模式没有多余台词或状态回流；设置入口始终可用。
- 字号、尺寸、主题、统计、音频等可见设置逐项核对；无效条件有解释。
- 配置迁移、Host 保存/刷新、浮层与完整设置同步、自定义规则和文案保留。
- 包构建、隔离原生测试、真实页面观察；不发送付费模型请求验证 UI。
