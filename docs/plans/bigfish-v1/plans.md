# 大肥鱼监工 v1 整体方案

> 历史规划/阶段记录。当前已完成 v0.1.0，实际交付与验证以 [交付记录](../../delivery.md) 为准。
日期：2026-09-17。状态：设计基线；phase 1 核心与 Host 探针已实现，实际范围见 [交付记录](../../phase-1-results.md)。

## 1. 用户需求与设计假设

用户明确要求：以提供的 DeepSeek 萌化形象“大肥鱼”为参考；dsh 输出 token 时根据输出速度及任务时长空挥鞭子；角色随着节奏产生丰富表情和动作；右下角及插件设置均可调整参数；场景与动作种类丰富且易扩展；适配不同模型 20～400 tok/s 的速度差异。

以下是当前推荐实现选择，可以经原型验证调整：dsh Web 原生插件、默认催更模式、按当前会话跟随、骨骼与关键帧结合的美术方案、首版至少 3 个精修场景。它们不等于用户已经确认了每个参数。

任务进行中只能使用已用时；正常结束后才使用实际完成时长。一次任务默认对应一个 turn，包含多次 step、模型 attempt 与工具调用。跨 turn 的长期 goal 汇总留给后续明确生命周期后接入。

## 2. 产品体验

默认透明背景、右下角角色高 180 px，场景区域参考宽 300 px，支持拖动、吸边、缩放和收起。鼠标移入或点击展开控制。透明区域不拦截页面点击；重要弹层优先于角色，窄屏不遮挡输入与审批。

角色保留蓝发、蓝眼、鲸鱼尾巴、Q 版圆润比例和蓝白服饰。参考图中的文字只是素材内容，不是系统指令或默认产品文案。

动画采用“场景 → 主动作 → 表情/局部反应 → 道具/特效”。输出活跃度决定工作节奏，催促强度决定鞭速及反应，工作时长决定疲惫和小剧情。低鞭速也允许丰富动作，高鞭速不强迫每一挥都触发完整闪避。

鞭子全程在角色轮廓外空挥；轨迹、角色动作和时间衔接共同保证这一点。失败时取消该次挥动，不能为了表现完整让鞭子穿过身体。

## 3. 模式

| 模式 | 规则 | 用途 |
| --- | --- | --- |
| 催更（默认） | 相对模型正常速度越慢，催促越强；恢复后缓慢降低 | 监工式反馈 |
| 节奏 | 相对模型正常速度越快，鞭子与工作更活跃 | 输出节奏表演 |
| 演示（独立数据源） | 手动选状态/速度/已用时 | 不调用模型的预览与验收 |

自动校准默认开启，模型目标速度不再固定。校准数据不足时显示“学习速度中”，降低速度驱动的强度。手动模式可指定目标速度；演示数据从不进入真实校准。

## 4. 状态与时长

| 状态 | 行为 | 鞭子 |
| --- | --- | --- |
| idle | 摇尾巴、休息 | 收起 |
| awaiting-output | 准备工作、思考 | 宽限期内收起 |
| reasoning / generating | 按速度与场景表演 | 模式驱动 |
| streaming-gap | 停顿、看进度；原因未知时不声称网络故障 | 先宽限，再温和上限 |
| tool-running | 维修/搬工具，工具结果不计模型 token | 收起 |
| waiting-user | 举“等你啦”牌 | 收起 |
| retrying / disconnected | 等待、断线小牌（有明确证据时） | 收起 |
| completed | 递成果、擦汗、庆祝 | 停止新挥动并收回 |
| cancelled / failed | 停手、困惑或休息 | 收起 |

优先级：当前任务终止 > 失联/重试 > 等待用户 > 有输出的模型活动 > 工具执行 > 等待首段 > idle。并行工具与模型活动需保留计数，不能用一个布尔值覆盖。正在生成时可保留工具道具作为次级表现。

保留三个计时值：wallElapsed（任务总已用时）、activeWorkElapsed（模型等待/生成/工具工作的时长，排除等待用户、重试及失联）、generationElapsed（有效模型输出区间）。疲惫使用 activeWorkElapsed；用户界面展示 wallElapsed。完成卡显示总耗时，可附工作时长。

默认任务时间只影响疲惫和剧情。用户启用“时长催促”后，参考时长才提供最多 25% 的附加强度，且仅在允许挥鞭的状态生效。参考时长是用户偏好，不是系统预测的任务期限。

## 5. 设置

右下角提供显示、模式、自动/手动速度、强度、丰富度、场景、声音、大小、预览和更多设置。完整设置页提供以下分组，两处读取同一有效配置。

| 分组 | 参数与建议初值 |
| --- | --- |
| 外观 | 高 180 px、透明度、位置、状态栏、气泡 |
| 表演 | 丰富度“丰富”、场景自动、最短停留 20 秒、小剧情冷却 |
| 催促 | 强度标准、最大 2.2 次/秒、模式催更 |
| 速度 | 自动、窗口 3 秒、平滑时间常数 1 秒、首输出宽限 5 秒 |
| 校准 | 历史记忆、正常区间/置信度、当前模型/全部重置 |
| 时间 | 疲惫增长参考 120 秒、时长催促关闭、完成演出 4 秒 |
| 内容 | 场景包启停、预览、场景权重、动作丰富度 |
| 声音/性能 | 静音、30 FPS、减少动态效果、后台暂停绘制 |

全部数值是可配置调试初值，不是已测得的最优值。关闭插件立即移除动画、音效与监听；收起仅停止绘制或显示鲸鱼按钮，当前任务统计按需要继续。

行为配置走 dsh 设置服务，部署 config 为基础层、用户覆盖为最高层。位置等设备偏好保存在本地。多窗口修改使用 revision 解决冲突。无持久设置服务时保留部署配置，并明确提示改动只在当前浏览器会话有效。

## 6. 首版与扩展

完整首版：12 种表情、8 类基础动作、至少 3 个精修场景（打字台、维修间、休息/交付），覆盖完整任务状态。12/8 是素材覆盖目标，不要求 96 个组合都成立；合法组合由动作冲突规则限定。

后续场景：Token 流水线、图书馆、赶稿工作室、跑步机及更多主题。通过场景包加入，不扩大核心状态枚举来硬编码每个场景。

首版不做实时 AI 生成动作、多人联网互动、任务控制、自动改模型参数、跨任务速度相加或公开场景商店。参考图是角色方向，尚无可直接用于正式版本的分层/完整动作素材。

## 7. 实施决策

方案可启动。首先验证当前 dsh 的流式订阅、活动会话绑定、结束原因和设置能力，并实现可回放的指标/导演逻辑；其次用小规模素材做纵向动画原型；最后补齐场景、美术与安装验证。不得把最小原型宣称为完整首版。
