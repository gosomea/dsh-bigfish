# 0.5.0 五项优化交付审查

本轮对应上一轮交付答复列出的五项：共享目录写入保护、完整备份恢复、低频动作精修、模块拆分、扩大验证范围。历史 review-0.4.3 的编号与答复不同；后台任务角标没有包含在本次五项里。

| 项目 | 本次落地 | 验证与边界 |
| --- | --- | --- |
| 共享目录 | Host 心跳锁、真实路径统一、目录 revision、整批恢复提交；离线库 IndexedDB 事务 | 多进程同时导入，符号链接同目录，持锁进程被杀后的恢复；混用旧插件、网络文件系统未验证 |
| 备份恢复 | 设置内导出 ZIP，校验与预览，角色合并、当前选择和偏好/台词/编排恢复 | 损坏/冲突/并发变化不覆盖；新增角色中途写入失败不发布半份目录；跨存储域不是整体原子事务 |
| 动作品质 | 新绘制 12 姿态；喝茶、擦汗、伸展各有准备/动作/收尾 | 运行时真实分帧，结束保持，轻柔/减弱动态策略仍生效；累计 72 姿态、29 类动作 |
| 可维护性 | 设置、行为预览、Canvas 路由、角色预览、素材注册、次级动作、布景分离 | 保留公开 UI 导出，原有浏览器回归通过；统一素材清单，销毁时解除所有图集回调 |
| 兼容性 | 实际 Linux arm64 Node 22.19.0 / 24.21.0 干净安装与构建测试；macOS rc.1 / rc.2 原生 Host 与浏览器；扩展真实时间 soak | 具体结果与时长见 compatibility / 最终验证 JSON；Windows、更早 DSH rc、跨天不标记通过 |

干净 Linux 构建发现旧源码归档未带 pnpm-workspace.yaml，导致 esbuild 构建许可丢失；本次已补齐源码打包清单。运行时新依赖 proper-lockfile 固定版本，保留 npm 安装机制，未把 Node require 误打进 ESM。

完整备份格式单独标识为 dsh-bigfish-backup v1，不改变角色包 1.0 协议。制作 Skill 继续是 dsh-bigfish-pet-maker 1.0.2；成年版角色包继续 1.0.0。新 daily 图集仅扩展内置 JSON 编排能力，旧编排可继续加载。

尚值得后续做的事：大备份在 Worker 解码以减少 UI 等待、异常中断恢复的持久日志、更长时间和更多真实 DSH 版本验收。角色参考的原作者仍未查明；本轮只补充实际生成过程记录。现阶段不再以增加设置数量作为优先目标。
