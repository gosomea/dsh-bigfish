# 常见问题、存储与备份

## 不想看到鞭子或躲闪

点击宠物齿轮，取消勾选“启用鞭策动作”。完整设置和 DSH 设置中的“大肥鱼监工”提供同一个开关。关闭后鞭子、配套反应和新鞭声音效停止；打字、读书、工具执行、完成反馈和速度显示继续。已发出的短音效可能自然结束，不会再触发下一次。

偏好刷新后保留，切换角色仍适用。重新开启会恢复上次选的“慢了催一催”或“跟着速度动”。若当前角色/动作档位没有反应素材，节奏控件不可用，但总开关仍可以关闭。角色库中手动预览某个躲闪动作属于素材检查，不会重新开启日常互动。

## 当前没动，但后台正在跑

宠物跟随当前打开的会话。后台任务不会相加计速，也不会抢占当前的完成/确认/报错表现。打开正在运行的会话会恢复其状态，速度重新采样；打开已完成会话不补播庆祝。当前未提供全局任务数角标或自动轮巡。

## 设置和角色存在哪里

| 内容 | 存储与范围 |
| --- | --- |
| 宠物行为、鞭策开关、自定义台词/工具规则 | DSH 的 bigfish 设置命名空间；宿主允许写入时持久保存。界面显示“当前会话有效”时只在内存生效 |
| 已导入角色包、版本与当前选择 | `$DSH_HOME/pets/dsh-bigfish/`；未设置 DSH_HOME 时为 `~/.dsh/pets/dsh-bigfish/`。同一个 Home 共用，不按 profile 分库 |
| 模型速度历史 | 当前浏览器同源 localStorage，键以 `bigfish.history.v1:` 开头；不保存对话正文 |
| 内置 JSON 动作编排 | 当前浏览器 localStorage：`bigfish.pack.v1` |
| 首次问候与空闲冷却 | 当前浏览器标签页 sessionStorage：`bigfish.idle.v2` |
| 离线演示页角色库 | 当前浏览器 IndexedDB：`dsh-pet-library`，与原生 Host 角色库独立 |

不同浏览器的 Host 角色选择通常在 15 秒轮询后同步；不同窗口的本地速度记录不是集中统计。不要把离线预览里安装角色误当成已经安装到日常 DSH。

## 如何备份或恢复

完整设置 → **备份与恢复** → 导出完整备份。恢复先校验并展示预览，确认后合并角色并恢复偏好和编排。不同内容的同版本不会覆盖；预览后发生并发改动会拒绝继续。详细范围、128 MiB 限制和中断处理见 [备份与共享存储](backup-and-storage.md)。

速度历史、宠物位置与首次问候冷却不进入备份。清理浏览器站点数据仍会丢失这些本地内容；Host 角色文件不受影响。卸载插件保留角色库和设置。

## 角色包与内置 JSON 有什么区别

`.dshpet` / ZIP 能换完整角色及其独立素材，允许多于内置预设的任意动作。高级设置中的 JSON 只能编排内置大肥鱼素材；它不是通用角色包。格式、体积和图片限制见 [角色包标准](pet-pack/spec.md)。

## 安装后仍是旧界面

先确认启动的 Web profile 与安装目标一致，再刷新页面。若 Host 没有重载旧模块，在当前任务结束后重启。使用本地 tarball 升级时先保留旧安装包，升级成功再清理。不要同时手动插入重复的插件 patch。详见 [安装排查](installation.md)。
