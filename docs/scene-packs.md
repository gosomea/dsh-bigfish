# 动作设计与场景扩展

v0.5.0：6 场景、29 类运动、72 张角色姿态。六张透明 PNG：classic 12 姿态、motions 16 连续动作帧、signs 16 举牌帧、work 8 阅读/工具姿态、quiet 8 待机/确认姿态、daily 12 喝茶/擦汗/伸展姿态。`assets/sprites/atlas-layout.json` 记录逐帧实际取图矩形，避免生成图集非等距排布造成串帧。

## 演出表

| 状态/场景 | 动作 |
| --- | --- |
| 无输入 / 休息小窝 | 首次问候后默认安静眨眼；仅选择偶尔/经常互动时，按预算随机高举牌、牌后探头、抱尾巴坐着举牌、小跳摇牌、招手、左右探头、摇尾巴、喝茶、伸懒腰、打盹 |
| 等待用户确认 | 专属伸手示意 → 收手等待，播完保持末帧，不反复举牌；无鞭 |
| 生成 / 打字台 | 交替敲键盘、缩肩、鼓脸碎步、回头、侧躲抱尾巴、手忙脚乱、擦汗、打勾 |
| 推理 / 图书馆 | 低头阅读、翻页、抬头思考、探头、茶杯；压力与疲惫影响反应 |
| 工具 / 维修间 | 拿起扳手、操作工具箱、检查结果、回头、擦汗；无鞭 |
| 高活跃 / 跑步机 | 踏步、加速、踉跄、站稳、紧张反应、擦汗 |
| 完成 / 交付舞台 | 招手、跳起、鞠躬、递稿、抱尾巴放松；持续设定秒数后回到等候 |
| 失败、取消、重试、失联 | 困惑、叹气、抱尾巴；气泡分别标识；不庆祝、不挥鞭 |

“举牌”包含拿起、抬高、展示、探头和放下的连续帧。五种演出都有不同手臂/身体图像，并随机编排；牌文为独立绘制层，中文/英文随宿主语言变化。默认文案“我在等哦”，其他变体为“等你派任务～”“有事叫我呀”“准备好啦！”。

生成过程的压力越高，动作序列播放速率逐步提高；主动作切换由动作档位控制并等待循环边界，允许更多回头、侧躲、慌忙反应。疲惫单独增加擦汗等变体；长任务额外催促默认关闭。导演优先避开最近三次动作，在动作末尾应用冷却和权重；测试使用固定种子复现。

如需替换角色和增加任意新动作，请使用 [角色包标准](pet-pack/spec.md)。下文 JSON 仅编排内置大肥鱼。

## 声明式动作包

从 `packs/classic/manifest.json` 复制 JSON，调整场景、状态、动作和帧序列后从“高级与重置 → 内置大肥鱼动作编排（JSON）”导入。导入支持内置六张图集，不执行脚本、不访问远程图片。JSON 上限 1 MB，schema/rig/资源/状态/帧序列错误会拒绝。自定义设置留在当前浏览器，可恢复默认包。

单个动作示例（放在支持 idle 的场景内）：

```json
{
  "id": "my-sign", "kind": "loop", "states": ["idle"],
  "pressure": [0, 1], "fatigue": [0, 1], "weight": 3,
  "durationMs": 6500, "cooldownMs": 12000,
  "channels": ["body", "arms", "props"],
  "entryPose": "center", "exitPose": "center",
  "envelope": {"x": 145, "y": 15, "width": 165, "height": 205},
  "sprite": 10, "motion": "sign-overhead",
  "animation": {"atlas": "signs", "frames": [0, 1, 2, 3], "fps": 2, "pingPong": true}
}
```

场景字段：`id/theme/states/minHoldMs/actions/whipHull/margin`。theme 复用 desk、library、workshop、treadmill、rest、delivery；新场景可以复用这些布景而不改核心。新增真正不同的布景需在 draw-scene.ts 增加道具绘制；新增整张美术图集需登记资源、帧坐标和解析器支持，然后重新构建。当前运行界面的动作覆盖使用 loop，纯导演保留 reaction/story 调度能力，未开放为运行界面的局部骨骼叠加。

帧序列支持 1～12 FPS、最多 64 个索引和 ping-pong；可选 loop:false 播放一次后保持末帧；内置 motions/signs 各有 16 帧，work/quiet 各有 8 帧，daily 有 12 帧。`sprite` 为 classic 0～11 的回退姿态。不要把 kind 或 motion 换成任意脚本。

## 永不接触

逻辑舞台为 340×250。完整角色/所有姿态最终裁剪到 x≥124；完整鞭子曲线和线宽裁剪到 x≤103，中间保持 21 个逻辑像素空带。动作包的 envelope 与 whipHull 还须通过 18 单位 margin 检查。缩放同比缩放两区域，拖动时停绘；切场景的 350 ms 过渡中关闭挥动。

约束对连续运动成立，不能通过设置关闭。截图用于检查画面，空间裁剪与包围盒测试用于证明不接触。鞭速最高可设 2.2 次/秒，默认音效关闭。

## 素材制作

角色生成与提示词见 [素材来源](asset-provenance.md)。新增动画优先制作可见手/头/尾巴变化的连续帧，再加程序关键帧；不要用增加随机全身抖动代替动作设计。动画试听页列出全部 29 类，可检查低速/高速和五种牌文。
