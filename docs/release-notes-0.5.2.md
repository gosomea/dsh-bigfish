# 大肥鱼 0.5.2 · 动作更从容，台词更丰富

## 安装 / 升级

```sh
dsh plugin --profile web add dsh-bigfish@0.5.2
dsh --profile web
```

已经运行 DSH 时，在任务空闲后重启并刷新页面。主要设置和已导入角色会保留。

## 本次更新

- **20 类 × 8 句，共 160 句默认台词。** 思考、写作、读文件、搜索、编辑、命令、测试、网页、并行任务、等待确认、失败、完成等类别全部补齐；保留 `{tool}`、`{file}` 等变量，并支持本轮任务提示 `{task}`。
- **默认更活泼。** 新设置每 20–40 秒出现一次空闲互动，动作展示 12 秒，气泡最多 6 秒；已有选择不被强制重置。内置大肥鱼有台词时每两次至少一次举牌，避开相邻重复。
- **空挥与工作姿态更稳定。** 一次空挥约 0.95–1.35 秒，恢复工作姿态保持 2.5 秒；去掉轮次间一帧闪回。正常动作按最短停留时间和循环边界轮转，连续工具调用合并目标，重要状态立即响应。
- **气泡跟随实际任务。** 显示当前用户消息的短提示、工具、文件和进度；同类工具的新调用也会更新文案。后台会话不会串入当前提示。不额外调用模型。
- **外部角色同步改进。** 反应期间暂停普通动作的播放时钟，一次性动作保留末帧，下一次空闲互动可以重播同一个问候。
- **角色制作 Skill 1.0.3。** 同步协议与 `{task}` 校验，随 npm 包分发，也可下载独立 ZIP。

## 台词如何生效

内置默认台词自动随升级更新。已有用户自定义类别或角色包专属台词仍优先；空列表继续表示静音。内置大肥鱼可在“自定义台词”中点“恢复这一类默认”采用新句子，也可以从 [完整台词模板](https://github.com/gosomea/dsh-bigfish/blob/main/docs/default-dialogue.json) 挑选追加。

安装随包 Skill：

```sh
npx --yes dsh-bigfish@0.5.2 install-skill
```

若目标已有不同内容的 Skill，安装器会保留并提示；可使用 `--skills-dir` 先安装到另一个目录对比。

动画设计与验证范围见 [0.5.2 审查](https://github.com/gosomea/dsh-bigfish/blob/main/docs/review-0.5.2.md)。本版沿用已有角色原画，没有把延长停留描述成新增原画帧。
