# 0.4.0 首版体验收尾与动作精修

本轮完成统一空挥绘制、外部角色固定站位、动作边界调度与速度累积、最近动作去重、确认状态优先级，以及高频动作素材接入。

新增 16 个独立绘制姿态：阅读 4、修理 4、待机眨眼 4、等待确认 4。内置共 60 个姿态、29 类动作、6 场景、5 种举牌。打字减少全身抖动；举牌加入停留与回收播放；确认手势只播一次后保持。低频动作仍有单姿态加程序动画，不将它们冒充独立逐帧美术。

设置显示当前角色在本档可用的动作数。缺少空挥能力或反应素材时解释原因并暂停该项；切换角色不丢失偏好。内置 JSON 编排移入“高级与重置”，与 `.dshpet` 角色包分开。

## v0.1.3 气泡合并

角色上方只保留一张信息卡，内含台词、单条状态/工具摘要、拖动/设置/收起按钮，以及运行期间的速度和计时。去掉底部独立工具栏；空闲时隐藏数据行。关闭消息气泡后，保留紧凑控制条，设置和收起入口仍可操作。
